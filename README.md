# agenda

Agenda de Medicina: planificador con vistas de día, semana (desde el lunes) y mes, una pestaña de tareas personales y asignaturas con color.

- `index.html`: la aplicación completa en un solo archivo, sin dependencias de compilación.

## Dónde se guardan las tareas

Las tareas no están en este repositorio. Dentro de claude.ai se guardan en el espacio privado de la cuenta. Si abres `index.html` fuera de claude.ai, se guardan en el almacenamiento local del navegador (solo en ese navegador y dispositivo).
